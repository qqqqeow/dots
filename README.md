# ❄️ Niri Custom Dotfiles (Glassmorphism & Modular)

Чистая, модульная и легковесная сборка рабочего окружения **Niri** на **CachyOS / Arch Linux** без Noctalia.

<p align="center">
  <b>Waybar</b> • <b>SwayNC</b> • <b>Kitty</b> • <b>Fuzzel</b> • <b>SwayOSD</b> • <b>Awww</b> • <b>Wallhaven</b> • <b>mpvpaper</b>
</p>

---

## ✨ Особенности
- **Низкое потребление памяти**: ~280–320 МБ в простое.
- **Стиль Glassmorphism**: Тонкое матовое стекло (`rgba(18, 20, 32, 0.65)`), размытие фона (Hardware Blur в Niri), парящие островки.
- **Интерактивная верхняя панель (Waybar)**:
  - 🖥️ **Переключение экранов и воркспейсов**: Кликабельные островки столов с переключением колесиком мыши.
  - 🎵 **Музыкальный плеер**: Клик по названию трека ставит на паузу/воспроизведение, правый клик — следующий трек, скролл — смена трека.
  - 🐱 **Catwalk**: Анимированный пиксельный котик, который идет спокойно при простое и ускоряется при нагрузке CPU. Клик открывает системный монитор `btop`.
  - 󰥔 **Время и дата**: Часы с выпадающим календарем.
  - 󰂚 **Уведомления и Центр управления (SwayNC)**: Индикатор со счетчиком непрочитанных и шторкой быстрых настроек.
  - 󰤨 **Сеть и Звук**: Слайдеры и статус Wi-Fi/Ethernet.
- **Обои (Mod+W)**:
  - Плавные анимированные переходы (grow, wave, disc, wipe).
  - Встроенный каталог **Wallhaven**: поиск и загрузка обоев по категориям (Топ, Hot, Аниме, Киберпанк, ручной поиск).
  - Поддержка **живых видео-обоев** через `mpvpaper` (`.mp4`, `.webm`).
  - Быстрое случайное переключение по `Mod+Shift+W`.
- **Терминал Kitty**: Стеклянная полупрозрачность (`0.78`), плавный трейл курсора, тема TokyoNight.
- **Навигация**: Управление окнами и мониторами через `Mod + Стрелки`.

## 🚀 Быстрый старт

```bash
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Mod + Enter` | Терминал Kitty (акриловое стекло) |
| `Mod + Space` | Поиск и запуск приложений (`Fuzzel`) |
| `Mod + N` | Центр управления и уведомления (`SwayNC`) |
| `Mod + V` | История буфера обмена (`Cliphist`) |
| `Mod + W` | **Меню обоев (Случайные / Wallhaven / Видео-обои)** |
| `Mod + Shift + W` | **Следующие случайные обои с анимацией** |
| `Mod + Стрелки (←↑→↓)` | **Навигация по окнам, колонкам и мониторам** |
| `Mod + Shift + Стрелки` | Перемещение окна/колонки в ленте или на другой экран |
| `Mod + 1 .. 5` | Переключение рабочих столов |
| `Mod + Shift + 1 .. 5` | Перемещение окна на рабочий стол |
| `Mod + [ / ]` | Переключение фокуса между мониторами |
| `Mod + R` | Смена ширины колонки (`33%` / `50%` / `66%`) |
| `Mod + Q` | Закрыть активное окно |
| `Mod + F` | Полноэкранный режим |
| `Mod + Shift + Space` | Переключить режим плавающего окна (Floating) |
| `Print` | Скриншот области экрана в буфер |
| `Mod + Shift + E` | Выход из Niri |
