# ❄️ Niri Custom Dotfiles (Glassmorphism & Modular)

Чистая, модульная и легковесная сборка рабочего окружения **Niri** на **CachyOS / Arch Linux** без сторонних монолитных шеллов (Noctalia-free).

<p align="center">
  <b>Waybar</b> • <b>SwayNC</b> • <b>Fuzzel</b> • <b>SwayOSD</b> • <b>Awww</b>
</p>

---

## ✨ Особенности
- **Низкое потребление памяти**: ~280–320 МБ в простое (против 700+ МБ у тяжелых шеллов).
- **Стиль Glassmorphism**: Тонкое матовое стекло (`rgba(18, 20, 32, 0.65)`), размытие фона (Hardware Blur в Niri), парящие островки.
- **Плавная физика**: Spring-анимации с рассчитанным коэффициентом затухания (`damping-ratio=0.85, stiffness=850`).
- **Собственный Центр управления**: Быстрые переключатели сети, звука, яркости, буфера обмена и уведомления через SwayNC.
- **Полная автоматизация**: Разворачивается одной командой через `./install.sh`.

---

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> ~/dotfiles
cd ~/dotfiles
```

### 2. Запуск установки
```bash
chmod +x install.sh
./install.sh
```

> **Примечание:** Скрипт сам установит нужные пакеты через `pacman`, создаст резервную копию существующих конфигураций в `~/.config/dotfiles_backup_*` и создаст символические ссылки.

## ⌨️ Основные горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Mod + Enter` | Терминал (`Alacritty`) |
| `Mod + Space` | Поиск и запуск приложений (`Fuzzel`) |
| `Mod + N` | Центр управления и уведомления (`SwayNC`) |
| `Mod + V` | История буфера обмена (`Cliphist + Fuzzel`) |
| `Mod + Q` | Закрыть окно |
| `Mod + H / J / K / L` | Навигация по бесконечной ленте Niri |
| `Mod + Shift + H / L` | Перемещение окна влево / вправо |
| `Mod + R` | Переключение ширины колонки (`33%` / `50%` / `66%`) |
| `Mod + F` | Полноэкранный режим |
| `Mod + Shift + Space` | Переключить режим плавающего окна (Floating) |
| `Print` | Скриншот выбранной области в буфер |
| `Shift + Print` | Скриншот экрана в файл |
| `Mod + Shift + E` | Выход из Niri |
